MemLevel Privacy Policy
Last updated: June 2026

1. Data We Collect
- Discord User IDs
- Message counts
- XP and level data
- Voice channel time
- Reaction counts
- Custom card settings (color, background)

2. How We Use Data
All data is used exclusively to provide MemLevel's leveling and leaderboard features. We do not use your data for advertising or analytics.

3. Data Storage
Data is stored locally on our servers and is not shared with any third parties.

4. Data Deletion
Server admins can delete user data using /removeuser. To request full data deletion, contact us via our support server.
